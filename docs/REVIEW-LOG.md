# REVIEW-LOG — 审查记账

> 双 agent 审查的长期沉淀。流程见 [WORKFLOW.md](WORKFLOW.md)。
> 最后更新：2026-09-10

**这份文件的价值全在于「不重复」**：同一个问题被指出两次、同一个争论吵两回，就说明该写进这里而没写。

三类东西往这里记：

1. **反复出现的问题** —— 同一类缺陷被指出 ≥2 次，说明是习惯性错误，要固化成约定
2. **已达成的约定** —— 争论之后定下来的做法，以后直接引用，不再重新论证
3. **被驳回的意见及理由** —— 审查提了但决定不改的，写清为什么，避免下次又提
